Privacy Policy

Last updated: 12 November 2026

Hai Video Stats does not collect, store, or share personal data of any TikTok user.

1. What the application accesses

With the operator's explicit authorization through TikTok Login Kit, the application accesses basic profile information (display name, open ID) and the video statistics of the operator's own TikTok account, using the TikTok Display API scopes user.info.basic and video.list.

2. Where data is stored

OAuth access and refresh tokens are stored locally on the operator's own computer in a plain file readable only by the operating-system account that created it. No data is transmitted to, or stored on, any third-party server, cloud service, or database.

3. Sharing

No data is sold, shared, published, or transferred to any third party. Aggregate statistics may be displayed privately to the operator in a local terminal or spreadsheet file.

4. Retention and deletion

Cached data lives only on the operator's computer and can be deleted at any time by removing the local token and CSV files. Authorization can be revoked at any time from the TikTok account's settings under Security & permissions → Manage app permissions.

5. Third-party services

The application communicates only with the official TikTok Open API endpoints at open.tiktokapis.com. No analytics, tracking, advertising, or crash- reporting SDKs are used.

6. Children

The application is not directed at children and processes no data relating to minors.

7. Changes

This policy may be updated at any time. The current version is always published on this page.
